# Vancouver & Metropolitan Vancouver — 3D Interactive Explorer

> A cinematic, real-time 3D interactive map and landmark explorer of **Vancouver & Metropolitan Vancouver, British Columbia**, powered by Three.js and Vite.

## Features
- **Cinematic 3D Viewport:** Interactive 3D landmark mesh rendering of downtown Vancouver, False Creek, and surrounding Metro Vancouver topography.
- **Interactive Points of Interest:** Real-time data integration, Wikipedia archives, and street-level imagery.
- **Live Atmosphere:** Real-time weather data and 24/7 visual stream archives of the Pacific Northwest.
